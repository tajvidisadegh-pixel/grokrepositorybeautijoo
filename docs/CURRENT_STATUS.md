## محصول چیست؟

مارکت‌پلیس رزرو نوبت برای **زیباگرها** (آرایش، ناخن، پوست، …) — فارسی و RTL.

### آنچه الان کار می‌کند (خلاصه)

| بخش | وضعیت تقریبی |
|-----|----------------|
| صفحهٔ اصلی، جستجو، پروفایل عمومی زیباگر | فعال |
| رزرو نوبت + پرداخت | مسیر اصلی پیاده شده؛ mock در پروداکشن باید بسته باشد (#77) |
| پنل کاربر (`/panel`) | رزروها، پروفایل، … |
| پنل زیباگر (`/zibagar`) | خدمات، ساعات، مکان، رزروها، نظرات، درآمد |
| پنل ادمین (`/admin`) | کاربران، کاتالوگ، رزرو، مالی، پشتیبانی، تنظیمات |
| اینماد / تماس / درباره ما | در سایت |
| SEO (Search Console، sitemap) | شروع شده؛ رتبهٔ برند فارسی به‌مرور |

### قوانین محصول مهم

- **پرداخت = نوبت قطعی** (زیباگر نوبت پرداخت‌شده را یک‌طرفه «رد» نمی‌کند).
- در UI فارسی واژهٔ **کاربر** به‌جای «مشتری»؛ **زیباگر** دست‌نخورده (#78).

## فایل‌های وضعیت قدیمی

این‌ها **منبع حقیقت فعلی نیستند**:

- `docs/STATUS.md` — فازهای اوایل پروژه (منسوخ)
- `docs/architecture/phases.md` — چک‌لیست فاز پیاده‌سازی قدیمی (منسوخ به‌عنوان وضعیت فعلی)

برای «الان کجاییم؟» فقط **همین فایل** را بخوانید.

سایر فایل‌های `docs/` (مثل CI، SMS، Locations، design system) مستندات موضوعی‌اند و لزوماً منسوخ نیستند.
